ESP MIDI
========

:link_to_translation:`en:[English]`

ESP MIDI 解析标准 MIDI 文件，并对音符开关、音色切换、控制器变化、弯音、通道压力以及速度、拍号等事件进行编码与解码。组件解析 SoundFont 2 与自定义音色库，经合成器输出 PCM。音频通过回调写出，并支持暂停、恢复、节拍与时基设置。
