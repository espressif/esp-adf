ESP Muxer
==================

:link_to_translation:`en:[English]`

ESP Muxer 是乐鑫为 ESP 系列 SoC 提供的多媒体封装组件，用于将音频、视频数据封装为标准媒体容器，或直接输出为流媒体数据，适用于录制、存储及网络传输等场景。

组件支持将音频、视频数据同步封装，兼容多种主流音视频编码格式，并支持多音轨、多视频轨、文件分片、流式输出及自定义写入接口。开发者可根据需求将数据保存至文件系统，也可输出至网络、Flash 或其他自定义存储介质，灵活适配不同应用场景。

ESP Muxer 采用模块化设计，兼顾高性能与低资源占用，可作为音视频采集、录制、直播推流及媒体分片等应用的数据封装模块，适用于行车记录仪、网络摄像机、HLS 分片服务、HTTP-FLV 推流等多媒体产品。
