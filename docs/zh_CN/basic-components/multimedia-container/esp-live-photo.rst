ESP Live Photo
==============

:link_to_translation:`en:[English]`

ESP Live Photo 是乐鑫为 ESP 系列 SoC 提供的 Live Photo（Motion Photo）生成与解析组件，使设备能够直接创建和解析兼容智能手机的动态照片文件，将静态 JPEG 图像与短时 MP4 视频封装为单一媒体文件。

组件支持 Live Photo 的完整生命周期，包括 JPEG 与 MP4 合成、XMP 元数据生成、MP4 定位及文件解析等功能，同时支持从 Live Photo 中提取 JPEG 封面和 MP4 视频。生成的文件可直接兼容支持 Live Photo 或 Motion Photo 的手机相册，无需服务器或 PC 后处理。

ESP Live Photo 采用轻量化设计，适用于智能摄像机、智能门铃、AI 相机及各类 IoT 设备，可用于拍摄带动态瞬间的照片、记录事件与分享影像。
