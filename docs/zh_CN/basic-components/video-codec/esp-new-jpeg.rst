ESP NEW JPEG
============

:link_to_translation:`en:[English]`

ESP NEW JPEG 是乐鑫为 ESP 系列 SoC 提供的轻量级 JPEG 编码与解码组件，针对嵌入式平台进行了内存占用和 CPU 性能优化，为图像采集、显示及存储提供高效的 JPEG 编解码能力。

组件支持丰富的像素格式、图像尺寸、色彩采样方式及图像质量配置，并提供图像旋转、缩放、裁剪等常用图像处理能力。同时支持整图模式和块处理模式（Block Mode），可根据内存资源灵活选择处理方式，满足高分辨率图像及资源受限场景的需求。

ESP NEW JPEG 采用轻量化、模块化设计，支持单任务和双任务运行模式，在保证较低资源占用的同时提供优异的编解码性能，适用于智能相机、IPC、AI 视觉、图片存储、图像传输及嵌入式图形应用等场景。
