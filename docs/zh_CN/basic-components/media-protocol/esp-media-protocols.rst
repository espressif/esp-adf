ESP Media Protocols
=======================================

:link_to_translation:`en:[English]`

ESP Media Protocols 是乐鑫为 ESP 系列 SoC 提供的官方媒体协议组件，提供主流流媒体传输、实时通信及设备互联协议的统一实现，用于构建多媒体网络应用。

组件集成了 SIP、RTSP、RTMP、MRM、UPnP 等常用媒体协议，覆盖 VoIP 通信、音视频流媒体、设备发现、多设备音频同步等典型应用场景。各协议均采用统一的组件化设计，可根据项目需求灵活选择和组合，降低协议集成与维护成本。

ESP Media Protocols 针对嵌入式设备进行了优化，在保证稳定性和较低资源占用的同时，提供完善的协议栈实现和易于扩展的接口，适用于智能音箱、IPC、流媒体播放器、智能家居设备、多房间音频系统等各类联网多媒体产品。
