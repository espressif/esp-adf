ESP Image Effects
=================

:link_to_translation:`en:[English]`

ESP Image Effects 是乐鑫为 ESP 系列 SoC 提供的轻量级图像处理组件，集成颜色空间转换、旋转、缩放、裁剪等基础图像处理能力，为图像采集、显示、编码及 AI 视觉等应用提供统一、高效的图像处理接口。

组件采用统一的 API 架构，支持丰富的 RGB、YUV 等像素格式，以及任意分辨率图像处理，并兼容 BT.601、BT.709、BT.2020 等主流色彩空间标准。同时支持任意角度旋转、图像缩放、区域裁剪及高性能颜色转换等功能，可根据不同格式和分辨率自动选择优化算法，在保证处理效率的同时减少数据转换开销。

ESP Image Effects 针对嵌入式平台进行了底层算法优化，并结合高效内存管理和硬件加速能力，实现高性能、低功耗、低内存占用，可广泛应用于智能摄像机、AI 视觉、工业检测、IoT 图像处理及各类嵌入式视觉产品。
