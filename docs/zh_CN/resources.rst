*********
相关资源
*********

:link_to_translation:`en:[English]`

* `esp32.com 论坛 <https://esp32.com>`_ 可用于提问与获取社区资源，其中设有 `ESP-ADF <https://esp32.com/viewforum.php?f=20>`_ 专区。

* 若发现缺陷或需要新功能，请查阅 GitHub 上的 `Issues <https://github.com/espressif/esp-adf/issues>`_。提交新 Issue 前请先检索已有条目。

* 如需参与 ESP 高级开发框架贡献，请参阅 `贡献指南 <https://docs.espressif.com/projects/esp-idf/zh_CN/latest/esp32/contribute/>`_。

* 关于 ESP32 的 `书籍 <https://www.espressif.com/en/ecosystem/iot-college/books>`_ 已有多部，可在 `乐鑫 <https://www.espressif.com/en/ecosystem/iot-college/books>`__ 官网查阅。

* 更多 ESP32 产品资料见乐鑫官网 `技术文档 <https://www.espressif.com/en/support/documents/technical-documents>`_ 栏目。

* 购买音频开发板可在乐鑫官网 `获取样品 <https://www.espressif.com/en/contact-us/get-sample>`__ 页面查看经销商列表。

* :doc:`音频示例 <audio-samples>`：可供音频项目使用的 PCM 与 MP3 示例文件。
