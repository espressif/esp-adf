*********
Resources
*********

:link_to_translation:`zh_CN:[中文]`

* The `esp32.com forum <https://esp32.com>`_ can be used to ask questions and obtain community resources. It has a dedicated section for `ESP-ADF <https://esp32.com/viewforum.php?f=20>`_.

* If you find a bug or need a new feature, please check the `Issues <https://github.com/espressif/esp-adf/issues>`_ on GitHub. Search existing entries before submitting a new issue.

* To contribute to the ESP Advanced Development Framework, please refer to the `Contributions Guide <https://docs.espressif.com/projects/esp-idf/en/latest/esp32/contribute/>`_.

* Several `books <https://www.espressif.com/en/ecosystem/iot-college/books>`_ about ESP32 are available and can be found on the `Espressif <https://www.espressif.com/en/ecosystem/iot-college/books>`__ website.

* For more ESP32 product materials, see the `Technical Documents <https://www.espressif.com/en/support/documents/technical-documents>`_ section on the Espressif website.

* To purchase audio development boards, see the list of distributors on the `Get Samples <https://www.espressif.com/en/contact-us/get-sample>`__ page of the Espressif website.

* :doc:`Audio Samples <audio-samples>`: PCM and MP3 sample files that can be used in audio projects.
